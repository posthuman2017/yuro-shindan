# 有料老人ホーム 簡易経営診断

介護付有料老人ホーム／住宅型有料老人ホーム／サービス付き高齢者向け住宅を対象とした、30問の簡易経営診断ツールです。回答するとレーダーチャート付きの診断書が生成され、そのまま印刷（PDF保存）できます。

## 使う

https://posthuman2017.github.io/yuro-shindan/

インストール不要、ブラウザだけで動きます。

## 特徴

- **6領域30問**：入居・収益力／コスト・収支構造／加算・報酬取得力／人材・組織／リスク・コンプライアンス／生成AI・生産性
- **施設類型で設問が分岐**：特定施設指定の有無により、加算に関する設問と、併設サービスへの依存（囲い込みリスク）に関する設問が切り替わります
- **生成AI成熟度 Lv.0〜4**：ガバナンス軸と実装軸の2軸で評価し、実装が先行してガバナンスが伴っていない「シャドーAI」状態を検出します
- **PDF出力**：診断結果画面の「PDFで保存」から、ブラウザの印刷機能でA4に出力できます
- **データ集計**：複数施設の診断結果をCSV／JSONで書き出せます。JSONは読み込みもできるため、別の端末で入力した結果を1台に集約できます

## 回答を集める設定

初期状態では回答は送信されず、端末内で完結します。メールでURLを配信して回答を集める場合は、以下の手順で受信先を用意してください。所要15分程度、費用はかかりません。

1. Googleドライブで新しいスプレッドシートを作成する（例：「有老経営診断_回答」）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 既存のコードをすべて消し、[gas/Code.gs](gas/Code.gs) の内容を貼り付けて保存する
4. 冒頭の `NOTIFY_TO` / `NOTIFY_CC` に通知先メールアドレスを設定する
5. 右上の「デプロイ」→「新しいデプロイ」→種類は「ウェブアプリ」を選び、
   **次のユーザーとして実行：自分** ／ **アクセスできるユーザー：全員** に設定してデプロイする
6. 初回は権限の承認を求められるので許可する（「詳細」→「（プロジェクト名）に移動」から進めます）
7. 発行された `https://script.google.com/macros/s/.../exec` をコピーし、[js/config.js](js/config.js) の `SUBMIT_ENDPOINT` に貼り付けてコミットする

設定すると、フォームに同意チェックと送信ボタンが表示され、送信のたびに以下が起こります。

- スプレッドシートの「回答」シートに1行追記される（そのまま集計・並べ替えができます）
- `NOTIFY_TO` 宛に、総合評価・領域別スコア・生成AI成熟度・優先課題5点をまとめたメールが届く
- 回答者の画面には診断結果が表示され、PDFとして保存できる

送信を止めたい場合は `SUBMIT_ENDPOINT` を空文字に戻してください。

補足：Gmailからの送信通数には1日あたりの上限（無料アカウントで100通程度）があります。一斉配信の規模が大きい場合は、通知メールを止めてスプレッドシートの集計のみで運用することもできます（`doPost` 内の `notify_(data);` を削除）。

## 個人情報の取り扱い

送信設定をしていない場合、入力内容はブラウザの中だけで処理され、外部へ送信されません。保存先は端末のlocalStorageのみです。共用端末で使う場合は、利用後に「保存・集計」タブから削除してください。

送信設定をしている場合、回答者が同意チェックを入れて送信ボタンを押したときにのみデータが送信されます。この点は画面上部と送信ボタンの直前の2か所で明示しています。送信先は上記で作成したご自身のGoogleアカウント配下のスプレッドシートで、第三者のサービスに蓄積されることはありません。

## 評価基準の出典

各設問のベンチマークは、以下の公開資料に基づいています。診断書の末尾にも出典を明記しています。

- 独立行政法人福祉医療機構「介護老人福祉施設・特定施設入居者生活介護の経営状況について」
- 厚生労働省「介護給付費等実態統計」「介護事業経営実態調査」
- 社会保障審議会 介護給付費分科会 資料
- 厚生労働省「2040年に向けたサービス提供体制等のあり方に関する中間とりまとめ」（2025年4月10日）
- 厚生労働省「介護現場における生産性向上ガイドライン」
- 個人情報保護委員会「生成AIサービスの利用に関する注意喚起等について」
- 厚生労働省「介護労働実態調査」
- 東京商工リサーチ 老人福祉・介護事業の倒産／休廃業・解散に関する調査

## 免責

本ツールは経営改善の論点を洗い出すための簡易診断であり、財務諸表監査・行政指導への適合性判定に代わるものではありません。全国平均の入居率、平均月額利用料、「入居率が何％を下回ると赤字」といった一律の閾値については公的統計が存在しないため、本ツールでは断定的な判定を避けています。

## 構成

```
index.html        画面（3タブ：診断入力／診断結果／保存・集計）
css/style.css     スタイル（印刷用CSSを含む）
js/questions.js   設問定義・配点・出典
js/score.js       採点ロジック・優先課題の抽出
js/chart.js       SVGチャート（外部ライブラリ非依存）
js/app.js         画面制御・保存・CSV/JSON入出力
```

ビルド不要です。ローカルで動かす場合は、このディレクトリで簡易サーバーを立てて開いてください。

```
python3 -m http.server 8719
```
